# 🧥 KI-Fundbüro - Katharineum zu Lübeck

Eine moderne, KI-gestützte Web-Anwendung zur Verwaltung und Zuordnung verlorener Kleidungsstücke für das Katharineum zu Lübeck.

## 🚀 Features
- **KI-Klassifikation**: Automatisches Erkennen von Kleidungsstücken mit TensorFlow/Keras.
- **Suche & Filter**: Durchsuchen aller Fundstücke nach Farbe, Kategorie, Fundort und Status.
- **Upload**: Einfaches Hochladen inklusive automatischer Vorschläge durch das KI-Modell.
- **Admin-Bereich**: Geschützte Verwaltung zum Ändern des Status, Löschen und Exportieren der Daten.
